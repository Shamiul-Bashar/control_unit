# Control Unit — CPU Architecture Lab

A 24-bit CPU architecture and digital logic circuit design implemented in Logisim for a Computer Architecture Lab assignment.

## Project Overview

This Logisim circuit contains a control-unit/data-path design with 24-bit registers and digital logic components for controlling data flow between registers and the processor datapath.

## Main Components

- 24-bit registers: A, B, C, and D
- Control unit sub-circuit
- D flip-flops
- ROM
- Splitters and signal routing
- Clock and reset inputs
- 24-bit data input
- Control and output signals
